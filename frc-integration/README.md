# FRC integration

Reserved for robot-side adapters, examples, and interface documentation. Robot language, library versions, communication transport, and competition season are undecided. This directory does not establish competition eligibility.

When an interface is selected, document wiring/configuration prerequisites, telemetry schema/version, units, timing, error handling, and dependencies. Include a minimal example and tests for disconnection, stale data, and incompatible messages. Keep secrets and deployment-specific settings out of examples.

Record the relevant season and rules review before competition use. See [architecture](../docs/architecture/system-overview.md) and [integration tests](../tests/integration/README.md).

# Hardware

Place editable Altium projects, schematics, PCB layouts, and project-owned libraries here when created. Add source subdirectories only when they contain real design files. Keep source libraries and project output-job definitions in version control; generated previews, history, and fabrication output are ignored.

No electrical design or ratings are defined yet. Document board revision, selected parts, connector pinouts, measurement paths, supply/protection boundaries, and design review outcomes alongside the design. Record external library provenance and licenses.

Before fabrication, document how outputs are generated, the tool version, review results, and the exact source revision. Publish reviewed fabrication packages as versioned release artifacts.

# Bench tests

Status: planning guidance only. No energized-test procedure or electrical limits are approved here.

Before testing hardware, prepare and review a board-specific procedure that identifies wiring, polarity, protection, equipment ratings, supply/load settings, stop conditions, and safe shutdown. Do not infer limits from this repository scaffold.

Each procedure should identify requirement IDs, board/firmware revisions, reference instruments and calibration status, measurement points, acceptance criteria, steps, recorded observations, and reviewer. Candidate validation topics are measurement accuracy, repeatability, thermal behavior, reset/recovery, and fault reporting; applicable limits remain TBD.

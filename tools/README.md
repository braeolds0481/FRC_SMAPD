# Tools

Place development, telemetry capture, calibration support, and analysis utilities here as needed. No utilities are implemented yet.

Each tool should document purpose, prerequisites, supported version, invocation, inputs, outputs, and failure behavior. For Python tools, add dependency metadata and use an isolated environment; commit a lockfile when the chosen workflow produces one. Keep secrets and large generated captures out of Git. Retain small, sanitized fixtures only when they support repeatable tests.
